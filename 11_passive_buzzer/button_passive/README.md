# Passive Buzzer + Push Button

## Overview

This project combines a **passive buzzer** with a **push button** using an Arduino Uno.

The buzzer produces a tone only while the push button is pressed.

## Components

* Arduino Uno
* Passive Buzzer
* Push Button
* Breadboard
* Jumper Wires

## Circuit Connections

### Passive Buzzer

* Buzzer `+` → Arduino **D8**
* Buzzer `−` → **GND**

### Push Button

* One side → Arduino **D12**
* Opposite side → **GND**

No external resistor is required because the Arduino's internal pull-up resistor is used.

## Working Principle

The button is configured using:

`INPUT_PULLUP`

This means the Arduino internally pulls the button pin HIGH.

* Button released → D12 reads **HIGH (1)**
* Button pressed → D12 is connected to GND → D12 reads **LOW (0)**

When the Arduino detects LOW, it activates the passive buzzer using the `tone()` function.

When the button is released, `noTone()` stops the buzzer.

## Important Functions

### `pinMode()`

Sets a pin as INPUT or OUTPUT.

### `digitalRead()`

Reads the current state of the push button.

### `tone()`

Generates a specific frequency on the passive buzzer.

Example:

`tone(buzzer, 1500);`

This produces a **1500 Hz** tone.

### `noTone()`

Stops the tone generated by the buzzer.

## Code

```cpp
const int buzzer = 8;
const int button = 12;

void setup() {
  pinMode(buzzer, OUTPUT);
  pinMode(button, INPUT_PULLUP);
}

void loop() {
  if (digitalRead(button) == LOW) {
    tone(buzzer, 1500);
  }
  else {
    noTone(buzzer);
  }
}
```

* Using a push button as an input
* Understanding `INPUT_PULLUP`
* Reading digital input using `digitalRead()`
* Generating sound using `tone()`
* Stopping sound using `noTone()`

## Troubleshooting

### Buzzer doesn't sound

* Check buzzer polarity.
* Make sure the buzzer `+` is connected to D8.
* Make sure the buzzer `−` is connected to GND.
* Make sure the button is connected between D12 and GND.

### Buzzer sounds continuously

Check that the button is connected correctly and that the code uses:

`INPUT_PULLUP`

with:

`digitalRead(button) == LOW`

## Project Result

The passive buzzer successfully produces a tone when the push button is pressed and stops when the button is released.
